# Research Process Records

This directory contains diagnostics that document evidence availability,
measurement gates, and analytical stopping decisions. These artifacts support
research provenance and reproducibility; they are not Results figures or
substantive empirical findings.

## Records

- [Intervention linkage and eligibility](intervention-linkage-and-eligibility.md) — complete
- `assets/Figure_mashiki_road_network_and_reported_restriction_overlap.png` — spatial-linkage process diagnostic
- `assets/supplementary/` — observation-coverage and measurement-audit supplements
- `assets/superseded/` — exploratory figures replaced by the final two-case Results package

Only the outputs explicitly marked `done` in AnaSOP Section 8 remain under
`data/results/`. Files in this directory document the analytical process and
must not be presented as main Results outputs.
